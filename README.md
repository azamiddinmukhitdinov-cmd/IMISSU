# Лианночка, я скучаю ♡

Интерактивная романтическая открытка: ваше совместное фото, имя Лианночки в центре и признание на 12 языках. Нажатие на фразу раскрывает её смысл; нажатие на фото или кнопку открывает письмо. Внутри письма — маленькое анимированное объятие.

Открытка: https://liannochka-imissu.creamy-bream-2918.chatgpt.site

Открытка работает без регистрации, внешних шрифтов, аналитики и серверной базы. Фото сохранено в исходном виде. При включённом уменьшении движения анимация отключается.

## Изменения

- `docs/index.html` — текст и структура открытки.
- `docs/styles.css` — оформление и мобильная версия.
- `docs/app.js` — переводы и взаимодействия.
- `docs/assets/us.jpg` — ваша фотография.

## Локальный просмотр

```sh
python3 -m http.server 8000 --directory docs
```

Открой http://localhost:8000. Зависимости устанавливать не нужно.

Для сборки в `dist/`:

```sh
node scripts/build.mjs
```

## GitHub Pages

В репозитории открой **Settings → Pages**, выбери **Deploy from a branch → main → /docs → Save**. Адрес после включения: https://azamiddinmukhitdinov-cmd.github.io/IMISSU/

`.openai/hosting.json` связывает проект с Sites; изменения в GitHub сами по себе не публикуются в Sites.
